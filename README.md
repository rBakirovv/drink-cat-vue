# drink-cat-vue

Drink Cat — веб-приложение кофейни на Vue 3 и TypeScript. Сейчас в нём можно посмотреть популярные напитки, открыть карточку напитка, выбрать объём, ввести номер телефона и настроить уведомления. Приложение можно установить как PWA.

Договорённости по архитектуре, тестам и Git — в [конституции проекта](CLAUDE.md).

## Контекст для бэкенда

Фронтенд запускается самостоятельно. Каталог хранится в исходниках, действия пользователя обрабатываются локально, HTTP API пока не подключён.

### Каталог и размеры

- На `/` карусель показывает четыре популярных напитка в порядке, заданном в [локальном каталоге](src/entities/drink/model/popularDrinks.ts). Карточка ведёт на `/drinks/:drinkId`, например `/drinks/cappuccino`. Страница ищет напиток в том же массиве и для неизвестного `drinkId` показывает «Напиток не найден». При размещении сборки прямое открытие `/drinks/:drinkId` должно отдавать `index.html`, так как используется история браузера. [Маршруты](src/router/index.ts).
- Карточке списка нужны `id`, `name`, `price`, `image`. Странице напитка также нужен `description`. Текущие `id` — строковые идентификаторы для URL (`latte`, `cappuccino`, `iced-coffee`, `flat-white`), `price` — число в рублях, `image` — путь к изображению в `public/`. При переносе каталога стоит сохранить идентификаторы, чтобы работали существующие ссылки. [Тип напитка](src/entities/drink/model/types.ts), [локальный каталог](src/entities/drink/model/popularDrinks.ts).
- На странице напитка доступны S (250 мл), M (350 мл) и L (450 мл). По умолчанию выбран M. Размеры одинаковы для всех напитков, выбор размера не меняет цену. Кнопка добавления отключена. Корзина и оформление заказа пока отсутствуют. [Страница напитка](src/pages/drink-detail/ui/DrinkDetailPage.vue).

### Вход по телефону

Форма на главной форматирует номер как `+7 (XXX) XXX-XX-XX` и активирует кнопку «Получить код» после ввода полного номера. Отправка формы меняет локальное состояние. Отправка SMS, поле для ввода кода и пользовательская сессия пока отсутствуют. [Форма телефона](src/pages/home/ui/PhoneDrawer.vue).

### PWA и уведомления

Переключатель в меню запрашивает разрешение браузера и сохраняет выключенное состояние локально в Cache Storage. Service worker принимает событие `push`, читает тело сообщения как обычный текст и показывает уведомление с заголовком `Drink Cat`, если уведомления не выключены. Подписка через `PushManager` и отправка push с сервера пока отсутствуют. [Переключатель](src/pages/home/ui/CatMenu.vue), [конфигурация PWA](vite.config.ts), [обработчик push](public/push-handler.js).

### Предлагаемый порядок интеграции

1. **Каталог.** Начать с `GET /api/drinks?popular=true` для карусели и `GET /api/drinks/:drinkId` для страницы напитка. Список возвращает популярные напитки в порядке показа, а запрос неизвестного `drinkId` возвращает `404`. До реализации согласовать формат суммы и валюты, адреса изображений и модель размеров, если цена или доступность зависят от объёма.
2. **Вход.** Добавить запрос кода и его подтверждение. Передавать номер в нормализованном виде `+7XXXXXXXXXX`. Согласовать срок действия кода, повторную отправку, лимиты попыток и способ выдачи сессии после подтверждения.
3. **Заказы.** Определить, что пользователь сможет добавить и как оформить заказ. Для варианта напитка согласовать идентификатор и цену, которую сервер проверяет при оформлении.
4. **Web Push.** Если сервер должен отправлять уведомления, добавить создание подписки во фронтенде, её регистрацию и удаление на сервере. Согласовать, должен ли переключатель отключать доставку на сервере или только показ на устройстве.

## Запуск для разработки

Нужен Node.js 22.18+ в ветке 22.x или Node.js 24.12 и новее.

```sh
npm ci
npm run dev
```

Открой адрес, который выведет Vite (обычно `http://localhost:5173`). Для VS Code рекомендуются расширения из [настроек проекта](.vscode/extensions.json), в том числе Vue (Official) и Oxc.

Чтобы открыть приложение на телефоне, подключи телефон и компьютер к одной сети Wi-Fi и открой на телефоне адрес из строки `Network` в выводе Vite.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запускает сервер разработки |
| `npm run type-check` | Проверяет TypeScript, в том числе в `.vue` файлах |
| `npm run lint` | Запускает Oxlint и ESLint, исправляет то, что можно исправить автоматически |
| `npm run format` | Форматирует `src/` через Oxfmt |
| `npx oxfmt --check src/` | Проверяет форматирование без правок |
| `npm run test:unit -- --run` | Запускает тесты Vitest один раз |
| `npm run test:e2e -- --project=chromium` | Запускает сквозные тесты Playwright в Chromium |
| `npm run build` | Проверяет типы и собирает приложение в `dist/` |

Перед первым запуском сквозных тестов установи браузер: `npx playwright install chromium`.

## Компоненты интерфейса

Используем [shadcn-vue](https://www.shadcn-vue.com/docs/installation/vite): компоненты добавляются в исходники проекта. Например:

```sh
npx shadcn-vue@latest add input dialog
```

CLI настроен на `src/shared/ui/`. Кнопка уже доступна через `import { Button } from '@/shared/ui/button'`. Компоненты импортируем локально; глобальной регистрации нет. Тема и Tailwind Preflight подключены в `src/assets/main.css`, тёмная тема следует системным настройкам.
